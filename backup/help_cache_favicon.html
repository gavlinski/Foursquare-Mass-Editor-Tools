🖼️ Como Atualizar o Favicon (Limpar Cache)

✅ Favicon atual:

Se você vê o favicon antigo aqui, o cache precisa ser limpo

⚠️ Por que o favicon não atualiza?
Os navegadores fazem cache agressivo de favicons para economizar banda e melhorar performance. Mesmo depois de substituir o arquivo, o navegador pode mostrar a versão antiga por dias.

🔧 Métodos para Forçar Atualização

1️⃣ Hard Refresh (Mais Rápido)

Chrome, Firefox, Edge:

  • Windows/Linux: Ctrl + Shift + R
  • Mac: Cmd + Shift + R

ou

  • Windows/Linux: Ctrl + F5
  • Mac: Cmd + Option + R

2️⃣ Limpar Cache Completo (Recomendado)

🌐 Google Chrome / Edge:

  1. Pressione Ctrl + Shift + Del (Mac: Cmd + Shift + Del)
  2. Selecione "Tempo todo" ou "Desde sempre"
  3. Marque "Imagens e arquivos em cache"
  4. Clique em "Limpar dados"

🦊 Firefox:

  1. Pressione Ctrl + Shift + Del (Mac: Cmd + Shift + Del)
  2. Selecione "Tudo" em Intervalo de tempo
  3. Marque "Cache"
  4. Clique em "Limpar agora"

🧭 Safari (Mac):

  1. Menu Safari → Preferências → Avançado
  2. Marque "Mostrar menu Desenvolver"
  3. Menu Desenvolver → Esvaziar Caches
  4. Ou pressione Cmd + Option + E

3️⃣ Limpar Apenas o Favicon (Específico)

Chrome/Edge:

  1. Abra uma nova aba anônima (Ctrl + Shift + N)
  2. Acesse diretamente: http://localhost/favicon.ico
  3. Pressione Ctrl + Shift + R
  4. Feche a aba anônima e recarregue a página principal

Firefox:

  1. Digite na barra de endereços: about:cache
  2. Clique em "List Cache Entries" em "disk"
  3. Procure por favicon.ico
  4. Clique no link e depois em "Delete"

4️⃣ Método DevTools (Para Desenvolvedores)

  1. Abra DevTools (F12)
  2. Clique com botão direito no ícone de recarregar
  3. Selecione "Esvaziar cache e recarregar forçado"

5️⃣ Forçar Nova Versão (Via URL Query String)

  1. Abra diretamente: http://localhost/favicon.ico?v=2
  2. Você verá o novo favicon
  3. Depois disso, o cache será atualizado

✅ Como Verificar se Funcionou

  1. Recarregue esta página
  2. Verifique o ícone no canto superior da imagem acima
  3. Verifique a aba do navegador
  4. Verifique os favoritos (se tiver adicionado)

🔄 Teste de Scroll

📍 Quanto ao problema do scroll:
Criei um arquivo de teste isolado para diagnosticar o problema:
  • 🧪 Teste de Preservação de Scroll

Abra o link acima, siga as instruções e verifique no Console do navegador (F12 → Console) se aparecem as mensagens de salvamento e restauração da posição.

🐛 Debug do Scroll

Para verificar se o código de scroll está funcionando:

  1. Acesse qualquer página de debug (ex: test_session_debug.html)
  2. Abra o Console (F12 → Console)
  3. Role a página para baixo
  4. Clique em "Voltar para Debug"
  5. Verifique se aparecem as mensagens:
    • 📍 Salvando posição: XXXpx
    • ✅ Posição salva
  6. Na página index.php, verifique se aparece:
    • 🔄 Restaurando scroll para: XXXpx
